**Title:** Laspoh Proof — The AI Agent That Cannot Mark Its Own Work | Google All Things Agentic

**Description:**
I told a browser agent to apply to jobs — never recruitment agencies. It applied to ten; five
were recruiters; then it reported success. Laspoh Proof is the system I built so that can never
happen again: the agent doing the work is never allowed to decide the work succeeded, and
irreversible steps need a proven license BEFORE they execute. No proof, no done.

Built for the Google All Things Agentic Hackathon (Taskmaster track) on Gemini 3.5 Flash via
Vertex AI, Genkit, Cloud Run and Firestore — with Gemma 4 as a demotion-only second-opinion
auditor and gemini-embedding-001 for citation forensics.

Code: https://github.com/zubairkhaliduk-create/laspoh-proof
This video shows an unedited, live execution against the deployed Cloud Run service. The demo
job board is a disclosed synthetic environment; the agent, browser, model calls and ground truth
are real.
